# FaVe Python dependencies -- pure-Python, pinned for reproducibility.
#
# Installing this into a clean virtualenv is all that the native "fast" test
# tier needs (no system packages, no compiler):
#
#     python3 -m venv .venv
#     . .venv/bin/activate
#     pip install -r requirements.txt
#     ./test.sh fast
#
# THE RULE FOR THIS FILE, and why it has exceptions. Everything listed here must
# install from a WHEEL on a bare runner. A package that compiles at install time
# drags a toolchain into the one tier whose whole value is that it runs anywhere,
# so such a package is installed by the Dockerfile / the CI composite action /
# fave/setup.sh instead, and the test that needs it belongs in `integration`, not
# `fast` (test.sh decides tier membership by dependency footprint, never by
# runtime). The deliberate exclusions, each a source build:
#
#     pybison==0.6.4    NATIVE build needing system flex/bison. Additionally must
#                       be installed with `--no-binary :all:` -- the prebuilt
#                       cp312 wheel segfaults at runtime. See the Dockerfile.
#     pycosat==0.6.6    ad6's in-process SAT solver. Ships NO wheel, so it needs
#                       python3-dev to build. test_ad6_translate.py is in the
#                       integration tier for exactly this reason.
#     JPype1==1.7.1     drives the APKeep/NDD backends in-process; needs a JVM,
#                       which no amount of pip can supply.
#
# Keep the pins below in step with the Dockerfile, which is the canonical
# definition of this project's environment; `./test.sh doctor` diffs the two.
